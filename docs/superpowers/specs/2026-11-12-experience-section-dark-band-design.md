# Experience section visual redesign

## Intent

Give the Experience section stronger visual presence inside the existing portfolio home page, while keeping the page flow and content in Portuguese and English.

## Design

Use a full-width charcoal band for the Experience heading, Evertec and employment period, and Software Engineer role. Follow it with the existing two responsibility rows and technology line on the light surface. Keep the section anchor in the main navigation, preserve responsive behavior, and keep old standalone URLs redirecting to this home section.

## Approaches

- **Selected — dark band with light responsibility rows:** connects the section to the hero’s charcoal palette and keeps the detailed copy easy to read.
- **Light editorial split:** keeps the current light background and two-column layout, but changes the hierarchy and spacing.
- **Responsibility cards:** makes each task a separate card; rejected to keep the portfolio’s open editorial layout.

## Scope

Change only the Experience section’s structure and styling. Do not add work history, claims, or new project content.
